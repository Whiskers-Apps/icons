# Icons
You are free to use any of this icons in your projects. They were made to work together by having the same design rules so they feel consistent:

1. Roundness
2. Same Padding
3. Same Thickness (except some inner details)
3. At least the max width or max height

> [!NOTE]
> The icons might be subject to change. Consider them as an ALPHA version of the icon set.
